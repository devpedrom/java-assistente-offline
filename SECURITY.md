# Relatar um problema de segurança

Os limites de escrita, ações permitidas, processos locais e ausência de acesso externo são partes críticas deste projeto. Relate escapes de diretório, execução não autorizada ou exposição de dados ao responsável.

Para problemas com detalhes sensíveis, não publique credenciais, arquivos privados ou instruções exploráveis em uma issue pública. Combine um canal privado com o responsável pelo repositório antes de enviar a reprodução. Ainda não há um canal privado dedicado nem prazo de resposta definido.

Este projeto está em desenvolvimento; não há versões com política formal de suporte. Ao corrigir uma falha, inclua um teste de regressão e registre os limites efetivamente verificados.
